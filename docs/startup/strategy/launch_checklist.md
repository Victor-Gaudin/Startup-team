# Launch Checklist: AI Agent Payments Dashboard

## Pre-Launch (The "Foundation")
- [ ] Finalize Stripe Connect / Link for Agents integration.
- [ ] Basic landing page with waitlist (Beehiiv/Substack for email collection).
- [ ] Terms of Service & Privacy Policy (Crucial for a financial tool).
- [ ] 5-10 Beta testers onboarded and active.
- [ ] "Explainer" video (90 seconds, high quality).

## Launch Week (The "Impact")
- [ ] Day 1: "Show HN" (Tues/Wed/Thurs preferred).
- [ ] Day 1: Twitter announcement thread + Tag influencers in the agent space.
- [ ] Day 2: Direct reach out to waitlist (First 100 invites).
- [ ] Day 3: Release "Getting Started" guide on Medium/Dev.to.
- [ ] Day 5: Q&A session on X Spaces or Discord.

## Post-Launch (The "Retention")
- [ ] Implement "Refer-a-Builder" program (Limit increases for referrals).
- [ ] Weekly "Changelog" email to all users.
- [ ] Set up Intercom/Crisp for real-time developer support.
- [ ] Monitor "Spend Limit Hits" - proactively reach out to users whose agents are hitting limits to help them optimize.
- [ ] Gather 3 video testimonials for the homepage.
